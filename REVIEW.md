# Questions for an independent reviewer

The author-directed implementation, analysis and manuscript checks do not constitute independent scientific review. This document invites substantive criticism without presuming a favorable verdict.

1. Do the paired controls support the stated conclusion about the need for explicit-instruction comparators, without implying equivalence or broad schema effects?
2. Are the dependent task/seed/condition observations and the separately scheduled serving packages described adequately?
3. Does the distinction between returned status and observed effects add useful browser-specific evidence beyond established interface validation principles?
4. Is the 500-to-5,000 ms intervention characterized accurately as a modified executor under shared-machine load, while preserving the original failed replays?
5. Can the recorded-evidence checks and source derivations be reproduced from these assets? Which command, file or missing dependency prevents it?
6. Which claims would change after a blinded application-level holdout with a prespecified practical margin? Which parts of the paper should be narrowed now?

For a reproduction report, record the asset SHA256, operating system, Python/Node/browser versions, exact command and raw error/output. Keep successful and failed attempts. Do not upload credentials or signed-in browser profiles.

No award, citation outcome, independent replication or reviewer endorsement is claimed.
